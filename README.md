# 🐾 CAT IN TERMINAL QUEST'S

CAT IN TERMINAL QUEST'S is a terminal-based RPG where every element of the adventure — from battles to exploration — comes to life through emojis and text-based mechanics.

This project isn’t just a game. It’s a Java programming experiment designed to push the boundaries of what’s possible in a console environment. The goal is to train logic and creativity, implementing real RPG mechanics such as:

- 🎮 Turn-based combat

- 🧭 Exploration through text commands

- ⚔️ Character progression and stats

- 💬 Interactive events and decisions

Unlike typical terminal games that rely only on path choices or static text, CAT IN TERMINAL QUEST'S aims to deliver a deeper experience — transforming the terminal into a fully playable RPG world.

> 💡 Purpose: Develop programming skills while having fun creating a minimalist yet expressive RPG system.
